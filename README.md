# Bank Account Management System

## Project Description
A console-based banking application developed using Core Java. This project allows users to perform basic banking operations through a menu-driven interface with password authentication.

## Features
- Check Account Balance
- Deposit Amount
- Withdraw Amount
- Change Account Password
- Password Authentication
- Exit Banking Application

## Technologies Used
- Java
- JDK
- Eclipse IDE

## Java Concepts Used
- Classes and Objects
- Constructors
- Encapsulation
- Getters and Setters
- Static Block
- Methods
- Conditional Statements
- While Loop
- Switch Case
- Scanner Class

## Project Structure
- Account.java – Handles account details and banking operations.
- AccountDriver.java – Handles user interaction and menu-driven operations.

## How to Run
1. Download or clone this repository.
2. Open the project in Eclipse or any Java IDE.
3. Compile Account.java and AccountDriver.java.
4. Run AccountDriver.java.
5. Follow the menu options displayed in the console.
